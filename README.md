🔐 SQL Injection Detection and Prevention System
A web security application that detects and blocks SQL injection attacks in user inputs to prevent unauthorized access and database manipulation. Built for demonstrating how to safeguard web applications from one of the most common web vulnerabilities.

🚀 Tech Stack
Frontend: HTML, CSS, JavaScript

Backend: Python (Flask / Django)

Database: SQLite / MySQL

Security Layer: Input sanitization, SQL pattern matching, request filtering

🛡️ Key Features
🔎 SQL Injection Detection
Detects suspicious SQL keywords, operators, and injection patterns in real-time.

🧼 Input Sanitization
Filters and escapes harmful inputs to prevent query manipulation.

🚫 Attack Prevention
Blocks execution of malicious queries and logs the attempt.

🗂️ Logging System
Logs malicious requests with IP, timestamp, and attempted payloads.

📊 Admin Panel (optional)
View flagged activities and adjust sensitivity levels (for advanced users).
